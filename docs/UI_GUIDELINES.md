# UI_GUIDELINES.md

## Conceito visual

Cyber-Minimalism / SaaS High-End

Interface limpa, tecnológica e premium.

---

# Paleta

Background: #080A0F

Surface: #121721

Accent: #00FF41

Text Primary: rgba(255,255,255,0.92)

Text Muted: rgba(255,255,255,0.70)

---

# Tipografia

## Títulos

Syne ou Lexend

Peso forte.

---

## Corpo

Inter

Leitura limpa.

---

# Glassmorphism

Aplicar moderadamente.

Exemplo:

- background translúcido
- bordas suaves
- blur leve

Evitar exagero.

---

# Componentes

UI deve possuir:

- Button
- Card
- Badge
- Input
- Textarea
- Modal
- Skeleton Loader

---

# Layout

Mobile-first.

Breakpoints principais:

- mobile
- tablet
- desktop
- widescreen

---

# Navegação

Mobile:

- tab bar inferior

Desktop:

- navbar tradicional

---

# Hero

Hero deve:

- comunicar velocidade
- comunicar confiabilidade
- destacar CTA
- usar visual tecnológico

---

# Assets visuais

Preferir:

- SVG
- WebP
- AVIF

Evitar imagens pesadas.

---

# Animações

Usar Framer Motion.

Evitar animações excessivas.

---

# Regra final

Design deve parecer:

moderno  
tecnológico
premium
