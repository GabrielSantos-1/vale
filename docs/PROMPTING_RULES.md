# PROMPTING_RULES.md

## Objetivo

Definir como interagir com agentes de código (Codex).

---

# Regras gerais

Sempre pedir tarefas pequenas.

Evitar prompts grandes e vagos.

---

# Prompt ideal

Exemplo:

"Implemente a Hero Section usando os componentes base e seguindo UI_GUIDELINES.md."

---

# Ordem de execução

1. ler documentação
2. entender arquitetura
3. implementar tarefa específica
4. validar segurança
5. validar responsividade

---

# Evitar

- pedir implementação completa do sistema
- pedir múltiplas sprints ao mesmo tempo
- pedir refatoração global sem necessidade

---

# Estratégia recomendada

Trabalhar incrementalmente.

Exemplo:

- criar componente
- revisar
- integrar
- testar

---

# Regra final

Se houver dúvida:

priorizar documentação do projeto.
