# PROJECT_BRIEF.md

## Nome do projeto

Verde Vale 2.0

## Resumo executivo

Verde Vale 2.0 é o redesign completo de um site de provedor de internet fibra óptica, saindo de um visual institucional genérico para uma identidade Cyber-Professional / SaaS High-End.

O projeto deve transmitir:
- velocidade
- modernidade
- confiabilidade
- autoridade técnica
- sofisticação digital

A proposta não é criar apenas uma homepage atraente, mas uma base robusta para o crescimento futuro do negócio.

---

## Objetivo principal

Criar um site de provedor de fibra com aparência premium, excelente desempenho, SEO técnico, responsividade real e fundação segura para expansão futura.

---

## Objetivos secundários

- melhorar percepção de marca
- aumentar conversão de leads
- facilitar consulta de cobertura
- destacar diferenciais técnicos
- oferecer experiência superior em mobile
- criar base para futura área administrativa e expansão funcional

---

## Problema atual a resolver

O visual institucional genérico não comunica inovação, velocidade nem autoridade técnica.

Isso reduz:
- impacto visual
- percepção de valor
- diferenciação frente a concorrentes
- credibilidade tecnológica
- potencial de conversão

---

## Visão de produto

O produto deve ser percebido como uma fusão entre:
- provedor de internet moderno
- marca técnica confiável
- interface premium de SaaS
- produto digital de alto padrão

---

## Pilares do projeto

### 1. Performance
O site deve ser leve, rápido e otimizado para boa experiência real.

### 2. Responsividade
A experiência precisa funcionar muito bem em telas pequenas, médias e grandes.

### 3. Segurança
A base deve nascer preparada para evitar falhas comuns em sistemas web.

### 4. Escalabilidade
A arquitetura deve permitir crescimento sem exigir reconstrução completa.

### 5. Clareza visual
A interface deve ser limpa, tecnológica e sem ruído desnecessário.

### 6. Conversão
Cada seção precisa contribuir para confiança e ação do usuário.

---

## Direção estética

### Conceito visual
Cyber-Minimalism / SaaS High-End / Tech Premium

### Paleta
- Background principal: `#080A0F`
- Accent principal: `#00FF41`
- Superfícies: `#121721`
- Bordas translúcidas com baixa opacidade
- Texto claro com hierarquia forte

### Sensação desejada
- premium
- técnico
- sofisticado
- rápido
- confiável
- moderno

### O que evitar
- fotos genéricas de pessoas sorrindo
- estética corporativa comum
- excesso de efeitos neon sem controle
- excesso de animação
- aparência de template barato
- blocos visuais poluídos

---

## Tipografia

### Títulos
- Syne ou Lexend
- peso forte
- alto contraste visual

### Corpo
- Inter
- leitura limpa
- boa densidade informacional

---

## Estrutura principal do site

### Páginas públicas planejadas
- Home
- Planos
- Cobertura
- Suporte
- Contato
- Status da Rede
- Sobre
- Política de Privacidade
- Termos

### Área administrativa planejada
- Login
- Dashboard
- Leads
- Planos
- Cobertura
- FAQ
- Status

---

## Hero Section

A Hero deve:
- causar impacto imediato
- comunicar velocidade e autoridade
- ter composição limpa
- evitar excesso de texto
- destacar CTA principal
- reforçar branding técnico

### Composição sugerida
- lado esquerdo: headline, subheadline, CTAs
- lado direito: elemento abstrato de fibra óptica / pulso de dados / estrutura 3D glass
- iluminação e contraste controlados
- nada genérico

---

## Seções estratégicas da Home

- Hero principal
- diferenciais técnicos
- planos em destaque
- grid de benefícios
- cobertura / disponibilidade
- prova de confiabilidade
- status / monitoramento
- FAQ resumido
- CTA final

---

## Estilo visual dos ativos

### Diretrizes
- abstrato
- tecnológico
- limpo
- sem banco de imagem genérico

### Elementos desejados
- fibra óptica macro com bokeh
- linhas de conexão em gradiente neon
- formas translúcidas
- ícones 3D minimalistas
- gráficos ou indicadores sutis de status/rede

---

## Diretrizes de UX

### Navegação
- mobile-first
- tab bar inferior em mobile
- navegação tradicional em desktop

### Conteúdo
- mensagens diretas
- linguagem técnica controlada
- escaneabilidade
- seções bem definidas
- CTAs claros

### Responsividade
- não apenas adaptar layout
- repensar hierarquia conforme tela
- manter usabilidade real em qualquer viewport

---

## Diretrizes de performance

- priorizar SVG
- usar WebP/AVIF
- limitar imagens pesadas
- usar skeleton loaders quando necessário
- reduzir JavaScript desnecessário
- otimizar LCP
- evitar efeitos visuais caros no carregamento inicial

---

## Diretrizes de segurança

O projeto deve nascer preparado para:
- validação server-side
- proteção contra XSS
- proteção contra SQL Injection
- proteção contra IDOR
- proteção contra abuso de formulários
- autenticação segura na área administrativa
- headers de segurança
- logs de auditoria em ações administrativas

---

## Perfil do usuário final

### Público residencial
Busca:
- velocidade
- estabilidade
- facilidade
- suporte
- confiança

### Público técnico / exigente
Busca:
- baixa latência
- consistência
- clareza de planos
- indicadores técnicos
- percepção de infraestrutura séria

---

## Resultado esperado

Ao final do MVP, o projeto deve entregar:

- presença digital premium
- site institucional forte
- excelente base visual
- fundação técnica correta
- backend inicial funcional
- lead capture
- consulta de cobertura
- área administrativa inicial
- possibilidade real de expansão futura

---

## Fora de escopo inicial

Não implementar no MVP:
- área do cliente completa
- billing
- integração profunda com ERP/ISP manager
- chatbot complexo
- CMS avançado com HTML arbitrário
- upload complexo de mídia por usuários
- multi-tenant completo

---

## Critério de sucesso

O projeto será bem-sucedido se alcançar:

- estética premium consistente
- boa experiência em mobile e desktop
- boa performance
- boa organização técnica
- segurança básica bem aplicada
- facilidade de evolução por sprint
- baixa chance de regressão arquitetural ao usar IA para desenvolvimento

---

## Diretriz final

Este projeto deve parecer construído por engenharia com direção de produto, não por montagem apressada de template.
